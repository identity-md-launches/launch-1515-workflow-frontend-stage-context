Browser suites use an EIP-1193 fixture and intercepted JSON-RPC responses; fixture addresses and balances are test data, never runtime configuration. They assert actual decoded transaction calldata and recipient addresses, exact approval amounts, zero native swap value, the nonzero hook, fee deductions and output minimums. Failure/rejection cases assert that no transaction was sent. Pending signing is held briefly in the fixture to verify duplicate-submission lockout. The mint event identifies the new card, including when another owned card already exists. An existing oversized mint allowance must first be reduced; a changed mint price is rejected before signing.

The local server starts/stops inside each test and serves the export under `/preview/`. Resource and script errors were zero. Checked viewports include 320×844, 390×844, 768×844 and 1440×900; taste also uses 320×700. Screenshots are emulated browser viewports, not physical phones.

WebKit initially lacked host libraries. Runtime packages were downloaded/extracted under `/tmp`, never installed into the source or export. A temporary launcher supplied the extracted library paths plus Mesa's local vendor JSON and a surfaceless EGL platform. The suite then completed normally. Reproduction on a machine with standard Playwright system dependencies only needs `HIC_BROWSER=webkit`; the optional `HIC_WEBKIT_EXECUTABLE` override supports the worker's isolated launcher. Temporary browsers, libraries, package downloads, shaders and npm cache are not submission artifacts.

## Remaining limits

No funded mainnet mint, approval, deposit, withdrawal, swap, trade, burn or ownership change was broadcast. Real wallet extension/hardware/mobile-browser integration, mempool behavior, gas costs, chain reorg behavior and execution under adversarial liquidity remain untested on the live chain. Receipt replacement/cancellation handling was source-reviewed, not driven by a real mempool replacement. Public RPC outages/rate limits remain an operational possibility; the app exposes retry, fallback and disabled verification states.

The frontend deliberately uses paginated reads rather than an off-chain indexer. Public leaderboard rankings cover loaded cards only, and event history covers the displayed block windows. Card values are quotes, not an oracle/NAV; USD context is unavailable. Hex address inputs are used because no ENS resolver configuration is supplied. No browser-generated private key is stored or exported; the approved public-address setup alternative is implemented.

Final gateway URLs, ENS/site naming and absolute social preview URLs are pending publisher work. The static export and evidence are complete before those checks. The design document's scoped location is the only intentional path deviation from the lower-priority root DESIGN.md sentence. No requester input was missing and no blocked marker was needed.
